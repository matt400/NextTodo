# NextTodo
Simple todo app written in React synchronized with database.


# Instrukcja uruchomienia projektu: 
##Wymagania: 
-Node.js 
-npm (instaluje się razem z Node.js)

##Sprawdzenie w konsoli: 
node -v
npm -v

Jeśli brak - zainstalować odpowiednią wersję Node z Nodejs.org.

## Uruchomienie
git clone https://github.com/matt400/NextTodo
cd NextTodo
npm install
npm run dev

Aplikacja odpali się domyślnie pod http://localhost:5173 (info o hostcie będzie w konsoli)
